Each content item in the feed is displayed as a full screen card. One card occupies the full visible screen area. The user scrolls vertically to move between cards, similar to TikTok or YouTube Shorts but without any algorithm.

**Video cards:**

- Video does not autoplay. The user taps to play.
- Video plays in full screen within the card.
- No loud controls. A minimal tap-to-play icon centered on the card. Controls fade in on tap and fade out after a moment.
- Sound is off by default. User taps to unmute.

**Image cards:**

- Image fills the card with proper aspect ratio maintained.
- Pinch to zoom supported.

**Text / Markdown cards:**

- Rendered markdown displayed cleanly within the card.
- Font and spacing should feel like a premium reading experience — generous line height, readable size.
- Supports all standard markdown: headings, bold, italic, lists, code blocks, links.
- Card scrolls internally if the content is longer than the screen.

**All card types:**

- A small discreet icon in the corner indicates content type (video, image, text).
- The private note attached to a card is hidden by default. A subtle icon at the bottom of the card reveals it on tap.
- No like buttons, no share buttons, no engagement metrics of any kind. This is a private personal feed.
- Cards respect the active theme colors.
