This is where the user's account and app settings live.

**Account section:**

- Display name and profile picture (stored on Cloudinary under the user's ID)
- Sign out option

**Appearance section:**

- Theme picker — shows all preset themes with a live preview card before applying
- Light / dark toggle for the active theme

**Content section:**

- View all uploaded content in a grid or list
- Delete individual content items (removes from Cloudinary and local cache)

**Design behavior:**

- All options are grouped and collapsed by default
- The screen should feel like a settings panel of a premium app — clean, quiet, nothing screaming for attention
