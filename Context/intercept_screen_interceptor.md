the  scrolling are of the feed. 

feed supports
- markdown
- videos
- images

- the user can add comments to the content like a note, this section will be hidden unless the user asks for it to show.
- The user can attach a private note to any content item. This note is personal and hidden by default. It is revealed only when the user explicitly taps to show it. Notes are stored per content item and persist across sessions.
- Feed order is fully randomized on every app open. The same content item will not appear within 10 items of itself in a single session. There is no chronological or algorithmic order.
- > When there is no internet connection, only text/markdown content is displayed in the feed. Image and video cards are hidden entirely until connection is restored.

Content-type
====================
the user can choose the content type in the top
- the user will specify the content type when he uploads. 
- the user can choose mixed content. 
- > Content can also be added via an external link (Instagram post, YouTube video, Google Drive, etc.). The app saves only the URL — no file is downloaded or stored. Rendering depends on the source being available.
