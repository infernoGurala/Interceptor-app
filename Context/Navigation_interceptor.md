The app uses a bottom navigation bar with three tabs:

1. **Intercept** — the main feed screen
2. **Jet** — the upload screen
3. **Profile** — the account and settings screen

**Bottom navigation bar design:**

- Floating — it does not sit flush at the bottom edge. It hovers slightly above it with rounded corners.
- Glassmorphism effect — frosted glass background, subtle blur, semi-transparent. Premium and glossy feel.
- The active tab is indicated by a soft glow or filled accent dot. No loud highlights.
- The bar fades out when the user is scrolling down the feed and reappears when scrolling up or when the user taps the screen.

**Screen transitions:**

- Smooth fade or slide transitions between tabs. Nothing abrupt.

**App entry flow:**

- Splash screen with app logo on launch.
- If the user is already signed in, go directly to Intercept (feed).
- If not signed in, show a minimal sign in / sign up screen. Email and password only. No social login for now.
- After sign in, go directly to Intercept (feed).
